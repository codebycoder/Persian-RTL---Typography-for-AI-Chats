# شخصی‌ساز فونت چت

افزونهٔ شخصی کروم برای تغییر فونت خواندن گفتگوهای ChatGPT با فونت‌هایی که روی سیستم نصب شده‌اند.

این پروژه برای استفادهٔ محلی است و در Chrome Web Store منتشر نشده. فایل فونت‌ها داخل افزونه بسته‌بندی، کپی، دانلود یا از CDN بارگذاری نمی‌شوند.

## ویژگی‌ها

- انتخاب فونت فارسی برای متن گفتگو در ChatGPT
- پیش‌نمایش زندهٔ فونت در پنجرهٔ افزونه (فارسی و انگلیسی)
- روشن و خاموش کردن شخصی‌سازی بدون از دست رفتن تنظیمات
- ذخیرهٔ تنظیمات در `chrome.storage.local` و اعمال روی تب‌های باز
- اعمال فونت روی پیام‌های کاربر و دستیار، باکس نوشتن پیام و Canvas
- جهت طبیعی متن فارسی، انگلیسی و مخلوط در پاراگراف‌های ChatGPT فقط با CSS (`unicode-bidi: plaintext`)
- برای پاسخ‌های دستیار Claude، تشخیص جهت بلوک به‌صورت محلی از روی غلبهٔ خط فارسی/عربی در برابر لاتین؛ بدون ذخیره یا ارسال متن پیام
- حفظ ظاهر مونواسپیس برای بلوک‌های کد و کد اینلاین

## پیش‌نیازها

- Node.js نسخهٔ ۲۰ یا جدیدتر
- [pnpm](https://pnpm.io/) نسخهٔ ۱۰
- مرورگر Google Chrome
- نصب بودن فونت‌های مورد نظر روی سیستم

## نصب

از ریشهٔ پروژه:

```bash
pnpm install
```

## توسعه

برای ساخت مجدد پوشهٔ `dist/` بعد از هر تغییر:

```bash
pnpm dev
```

کروم تا وقتی افزونه را Reload نکنید فایل‌های جدید را برنمی‌دارد.

بررسی‌های مفید:

```bash
pnpm typecheck
pnpm lint
pnpm test
```

## ساخت و بارگذاری در کروم

ساخت افزونهٔ Unpack‌شده:

```bash
pnpm build
```

سپس پوشهٔ `dist` را در کروم بارگذاری کنید:

1. دستور `pnpm build` را اجرا کنید.
2. صفحهٔ `chrome://extensions` را باز کنید.
3. **Developer mode** را روشن کنید.
4. روی **Load unpacked** کلیک کنید.
5. پوشهٔ `dist` را انتخاب کنید.

بعد از هر تغییر:

1. `pnpm dev` را روشن نگه دارید یا دوباره `pnpm build` بزنید.
2. در `chrome://extensions` روی افزونه **Reload** بزنید.
3. پنجرهٔ پاپ‌آپ را ببندید و دوباره باز کنید.
4. تب‌های `https://chatgpt.com/*` را Refresh کنید تا content script دوباره تزریق شود.

تغییر تنظیمات از پاپ‌آپ، بدون Refresh صفحه روی تب‌های باز ChatGPT اعمال می‌شود؛ به شرطی که content script هنوز در حال اجرا باشد. بعد از Reload خود افزونه، صفحهٔ ChatGPT را یک بار Refresh کنید.

## فونت‌های پشتیبانی‌شده

نسخهٔ فعلی چهار خانوادهٔ نصب‌شده روی سیستم را پیشنهاد می‌دهد. نام نمایشی با نام واقعی `font-family` لزوماً یکی نیست.

| شناسه | فارسی | انگلیسی |
| --- | --- | --- |
| `yekan-bakh` | یکان بخ | Yekan Bakh |
| `peyda` | پیدا | Peyda |
| `iran-yekan` | ایران یکان | Iran Yekan |
| `estedad` | استعداد | Estedad |

اگر ChatGPT فونت را اعمال نکرد، نام واقعی جداول فونت را بررسی کنید:

```bash
pnpm fonts:inspect
```

سپس `candidateFamilyNames` و `localFaceNames` را در `src/shared/font-registry.ts` اصلاح کنید.

## ساختار پروژه

```text
src/popup/       رابط پاپ‌آپ (HTML، CSS و TypeScript)
src/content/     اسکریپت محتوا، سلکتورهای ChatGPT و موتور فونت
src/shared/      تنظیمات، ذخیره‌سازی، رجیستری فونت و تشخیص نصب بودن فونت
scripts/         لودر تست و ابزار خواندن نام فونت در macOS
public/icons/    آیکون‌های افزونه
fonts/           رزرو شده؛ فعلاً فایل فونت همراه پروژه نیست
manifest.json    منبع Manifest V3
dist/            خروجی افزونه بعد از بیلد
```

## حریم خصوصی جهت متن Claude

تشخیص جهت بلوک‌های دستیار Claude فقط داخل content script و همان لحظه انجام می‌شود. افزونه متن پیام را ذخیره، لاگ، ارسال، یا در `chrome.storage` نگه نمی‌دارد. تنها اثر ماندگار، ویژگی DOM متعلق به RastText است:

`data-rasttext-dir="rtl"` یا `data-rasttext-dir="ltr"`

با خاموش شدن افزونه همین ویژگی حذف می‌شود و `dir` اصلی Claude دست‌نخورده می‌ماند. ChatGPT از این مسیر جاوااسکریپتی استفاده نمی‌کند.

## دسترسی‌ها

افزونه فقط مجوز `storage` را برای `chrome.storage.local` اعلام می‌کند. `host_permissions` ندارد و content script فقط روی `https://chatgpt.com/*` اجرا می‌شود. دسترسی Local Font Access درخواست نمی‌شود.
