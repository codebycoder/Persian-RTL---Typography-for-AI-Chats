# راستا

افزونهٔ شخصی کروم برای تغییر فونت گفتگوهای ChatGPT و Claude با چند فونت فارسی/عربی متن‌باز و امکان افزودن فونت دلخواه کاربر.

این پروژه برای استفادهٔ محلی است و در Chrome Web Store منتشر نشده. فونت‌های آماده داخل خود افزونه قرار دارند و هیچ فونتی از CDN دریافت نمی‌شود.

## ویژگی‌ها

- انتخاب فونت فارسی برای متن گفتگو در ChatGPT
- چهار فونت رایگان همراه افزونه: وزیرمتن، استعداد، Noto Sans Arabic و Noto Naskh Arabic
- افزودن، جایگزینی و حذف یک فونت شخصی با فرمت WOFF2، WOFF، TTF یا OTF (تا ۴ مگابایت)
- پیش‌نمایش زندهٔ فونت در پنل کناری افزونه (فارسی و انگلیسی)
- روشن و خاموش کردن شخصی‌سازی بدون از دست رفتن تنظیمات
- ذخیرهٔ تنظیمات در `chrome.storage.local` و اعمال روی تب‌های باز
- اعمال فونت روی پیام‌های کاربر و دستیار، باکس نوشتن پیام و Canvas
- اعمال فونت و تشخیص جهت فارسی/انگلیسی هنگام تایپ در کامپوزر معمولی و بخش Design / Design System در Claude
- اعمال فونت و جهت مستقل هر پاسخ در کارت «You answered» کلاد (`question-receipt`)، با پشتیبانی از پاسخ فارسی پس از برچسب انگلیسی
- اعمال فونت فارسی روی عنوان چت‌های سایدبار Claude، شامل چت‌های داخل پروژه‌ها
- اعمال فونت فارسی روی عنوان چت‌ها در جدول فهرست گفتگوهای Claude، با حفظ چپ‌چین بودن و ترتیب درست متن ترکیبی فارسی و انگلیسی
- تشخیص جهت بندها و فهرست‌های فارسی/انگلیسی ChatGPT، با پشتیبانی از پاسخ‌های در حال تولید و جداسازی جهت قطعه‌کدها
- برای پاسخ‌های دستیار Claude، تشخیص جهت بلوک به‌صورت محلی از روی غلبهٔ خط فارسی/عربی در برابر لاتین؛ بدون ذخیره یا ارسال متن پیام
- حفظ ظاهر مونواسپیس برای بلوک‌های کد و کد اینلاین

## پیش‌نیازها

- Node.js نسخهٔ ۲۰ یا جدیدتر
- [pnpm](https://pnpm.io/) نسخهٔ ۱۰
- مرورگر Google Chrome نسخهٔ ۱۱۴ یا جدیدتر

## نصب

از ریشهٔ پروژه:

```bash
pnpm install
```

## توسعه

برای ساخت مجدد پوشهٔ `dist/` بعد از هر تغییر:

```bash
pnpm dev
```

کروم تا وقتی افزونه را Reload نکنید فایل‌های جدید را برنمی‌دارد.

بررسی‌های مفید:

```bash
pnpm typecheck
pnpm lint
pnpm test
```

## ساخت و بارگذاری در کروم

ساخت افزونهٔ Unpack‌شده:

```bash
pnpm build
```

سپس پوشهٔ `dist` را در کروم بارگذاری کنید:

1. دستور `pnpm build` را اجرا کنید.
2. صفحهٔ `chrome://extensions` را باز کنید.
3. **Developer mode** را روشن کنید.
4. روی **Load unpacked** کلیک کنید.
5. پوشهٔ `dist` را انتخاب کنید.
6. روی آیکن راستا در منوی افزونه‌ها کلیک کنید تا پنل کناری باز شود. پنل هنگام جابه‌جایی بین تب‌ها باز می‌ماند و وضعیت تب فعال را به‌روز می‌کند.

بعد از هر تغییر:

1. `pnpm dev` را روشن نگه دارید یا دوباره `pnpm build` بزنید.
2. در `chrome://extensions` روی افزونه **Reload** بزنید.
3. پنل کناری را ببندید و با کلیک روی آیکن راستا دوباره باز کنید.
4. تب‌های ChatGPT و Claude را Refresh کنید تا content script دوباره تزریق شود.

تغییر تنظیمات از پنل کناری، بدون Refresh صفحه روی تب‌های باز ChatGPT اعمال می‌شود؛ به شرطی که content script هنوز در حال اجرا باشد. بعد از Reload خود افزونه، صفحهٔ ChatGPT را یک بار Refresh کنید.

## فونت‌های پشتیبانی‌شده

نسخهٔ فعلی چهار خانوادهٔ متن‌باز را همراه افزونه ارائه می‌دهد؛ بنابراین نیازی به نصب آن‌ها روی سیستم نیست.

| شناسه | فارسی | انگلیسی |
| --- | --- | --- |
| `vazirmatn` | وزیرمتن | Vazirmatn |
| `estedad` | استعداد | Estedad |
| `noto-sans-arabic` | نوتو سنس عربی | Noto Sans Arabic |
| `noto-naskh-arabic` | نوتو نسخ عربی | Noto Naskh Arabic |

فایل‌ها و متن کامل مجوز SIL Open Font License 1.1 هر خانواده در پوشهٔ `fonts/` قرار دارند. مشخصات منبع در [fonts/LICENSES.md](fonts/LICENSES.md) ثبت شده است.

### افزودن فونت شخصی

از تب **تنظیمات** پنل کناری روی **افزودن فونت** بزنید و یک فایل WOFF2، WOFF، TTF یا OTF تا سقف ۴ مگابایت انتخاب کنید. فایل فقط در `chrome.storage.local` همان پروفایل مرورگر ذخیره می‌شود، به هیچ سروری ارسال نمی‌شود و هر زمان قابل حذف یا جایگزینی است.

## ساختار پروژه

```text
src/sidepanel/   رابط پنل کناری (HTML، CSS و TypeScript)
src/background/  راه‌اندازی باز شدن پنل با کلیک روی آیکن
src/content/     اسکریپت محتوا، سلکتورهای ChatGPT و موتور فونت
src/shared/      تنظیمات، ذخیره‌سازی، رجیستری و اعتبارسنجی فایل فونت
scripts/         لودر تست و ابزار خواندن نام فونت در macOS
public/icons/    آیکون‌های افزونه
fonts/           فونت‌های متن‌باز همراه افزونه و فایل‌های مجوز آن‌ها
manifest.json    منبع Manifest V3
dist/            خروجی افزونه بعد از بیلد
```

## حریم خصوصی جهت متن Claude

تشخیص جهت بلوک‌های دستیار Claude فقط داخل content script و همان لحظه انجام می‌شود. افزونه متن پیام را ذخیره، لاگ، ارسال، یا در `chrome.storage` نگه نمی‌دارد. تنها اثر ماندگار، ویژگی DOM متعلق به RastText است:

`data-rasttext-dir="rtl"` یا `data-rasttext-dir="ltr"`

با خاموش شدن افزونه همین ویژگی حذف می‌شود و `dir` اصلی Claude دست‌نخورده می‌ماند. ChatGPT از این مسیر جاوااسکریپتی استفاده نمی‌کند.

## دسترسی‌ها

افزونه مجوز `storage` را برای ذخیرهٔ محلی و مجوز `sidePanel` را برای نمایش پنل کناری کروم اعلام می‌کند. `host_permissions` ندارد و content script فقط روی `https://chatgpt.com/*` و `https://claude.ai/*` اجرا می‌شود. دسترسی Local Font Access درخواست نمی‌شود.

## آزمون مرورگری جهت ChatGPT و Claude

پس از `pnpm build`، با Playwright CLI نمونهٔ محلی را اجرا کنید (درخواست صفحه به ChatGPT ارسال نمی‌شود):

```sh
npx --package @playwright/cli playwright-cli open about:blank
npx --package @playwright/cli playwright-cli run-code --filename scripts/verify-chatgpt-direction.js
npx --package @playwright/cli playwright-cli run-code --filename scripts/verify-claude-direction.js
npx --package @playwright/cli playwright-cli run-code --filename scripts/verify-table-direction.js
```

این آزمون‌ها فهرست‌های تودرتو، اعداد ابتدای متن انگلیسی، کد، ترتیب ستون‌ها و تراز جدول‌های ترکیبی فارسی/انگلیسی، پاسخ تدریجی، نمایش موبایل و خاموش/روشن‌کردن افزونه را بررسی می‌کنند.
